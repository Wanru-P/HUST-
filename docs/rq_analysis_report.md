### 必须写明的限制

- **首月（2022-03）存在时间戳异常聚集（已观测现象）**：2022-03-02 单日即集中 29,573 个模型，占首月 32,621 个的 90.7%；而该日只有 5 个不同时间戳，其中 `2022-03-02T23:29:05.000Z` 一个时间戳就占 21,869 个（73.9%）。以上是**已观测到的现象**：同一时间戳在最早一天高度聚集，与逐日发布过程不符，因此**不能**解读为「自然发布高峰」。仅凭本快照**无法确认根因**（既可能是平台早期元数据的迁移写入，也可能是时间戳记录下限，二者都缺少可核验证据），故**不作因果推断**；受此影响，首月数值不可与其他月份直接比较。
- `pipeline_tag` 缺失率 **65.55%**。缺失**未被推断**成任何具体任务，统一记为 `unknown` 并单独报告；所有按任务的分析结论**只覆盖已标注任务的那部分模型**。
- 因此不能宣称「某些任务主导了 HF 生态」而忽略 65% 以上的缺失；能说的是「在已标注任务的模型里，构成如何」。
- 2026 年只覆盖 1—10 月，年际比较需注意覆盖不全。

## 2. RQ2 主要结果

口径说明：`downloads` 为**近 30 天**下载计数，`downloadsAllTime` 为**历史累计**下载计数。两者在本快照上相差约 27.2 倍，**任何集中度结论都必须声明所用口径，不可混用、不可相加**。

计算方法：Gini 由 `stats_utils.gini_freq_weighted`（频数加权秩公式）**精确**计算，不是采样近似；Top-p 份额按值降序取前 `max(1, int(n·p))` 个模型，并列值整体同权，结果与并行度、输入顺序无关（见 `test_algorithms.py`）。

| 指标 | downloads（近 30 天） | downloadsAllTime（累计） |
| --- | --- | --- |
| 模型数 | 3,138,954 | 3,138,954 |
| 合计下载量 | 2,788,919,780 | 75,949,397,771 |
| 不同取值数 | 14,894 | 47,869 |
| Gini | **0.995355** | **0.998117** |
| Top-1% 份额 | 97.1272% | 98.7017% |
| Top-5% 份额 | 99.0904% | 99.6536% |
| Top-10% 份额 | 99.4817% | 99.8409% |
| 零下载模型数 | 1,366,793 | 1,317,858 |
| 零下载占比 | 43.54% | 41.98% |

### 结论（严格限定）

- 注意力极度集中：Top-1% 的模型占据 97.13% 的近期下载量，Gini = 0.995355。
- 同时存在大规模「零注意力」长尾：43.54% 的模型近 30 天下载为 0。
- **不宣称幂律分布**：本分析只描述长尾形态（Lorenz 曲线显著偏离对角线、CCDF 在双对数坐标下近似直线），并未做严格的分布拟合与模型比较，因此不能声称「已验证幂律」。
- 下载量只反映传播热度，**不代表模型质量**，也不代表技术先进性。
