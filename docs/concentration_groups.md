## 1. 为什么要做这一步

原 RQ2 给出的是**总体**集中度（Gini / Top-k / 零值占比）。一个自然的追问是：**这种极端不均衡到底来自哪里？**

本节**不改变**原 RQ2 的任何结果，只是在它之上补做**分组分解**：把模型按「任务类型」「创建年份」「有无显式血缘」分组，再用 **Theil T 指数**把总体不均衡拆成**组间贡献**与**组内贡献**。

---

## 2. 方法与公式

Theil T 指数（只对正取值有定义；零值单独报告）：

```
T = (1/n) · Σ (x_i / μ) · ln(x_i / μ)
```

组间 / 组内分解：

```
T_total = Σ_g s_g · T_g        （组内贡献 T_within）
        + Σ_g s_g · ln(μ_g / μ)（组间贡献 T_between）
```

其中 `s_g = 组 g 的取值和 / 总和`，`μ_g` 为组均值，`μ` 为总均值。`between_share = T_between / T_total`：
**越接近 0 说明差异主要发生在组内，越接近 1 说明差异主要来自组与组之间。**

> 零值处理：`downloads` 口径下大量模型为 0，Theil 只用正取值计算，零值占比在各组的 `per_group` 中单独给出。

## 5. 限制

1. 两种下载口径**分别计算、不可混用、不可相加**；
2. 分组只是描述维度，**组间差异不构成因果**；
3. 小分组（模型数很少）的 Gini/Theil 噪声大，汇总对比以组规模 ≥ 1000 的组为主；
4. `has_lineage` 只表示「该模型是否出现在血缘边的 dst 端」，不代表血缘完整性（底座关系缺失率很高）。
