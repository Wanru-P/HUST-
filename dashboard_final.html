RQ1 · 生态演化

研究对象是「快照中仍可见模型的创建时间分布」，不是历史上所有曾发布模型的完整记录。 峰值月 2024-09（125,030 个）；2026-10 为快照截止月，尚未走完，不与完整月份直接比较。

首月 2022-03 存在时间戳异常聚集：约 90.66% 的模型挤在 2022-03-02 一天，而该日只有 5 个不同时间戳。 这是已观测到的现象；根因未确认（平台元数据迁移 / 时间戳记录下限等解释均缺可核验证据）， 故不作因果推断，也不当作自然发布高峰。

口径与限制（易混淆项）

易混淆的两侧正确表述
下载热度 / 模型质量下载量只反映传播热度，不等于质量
PageRank / 模型质量只反映图结构中的被引用强度，不等于质量
同期统计关联 / 前瞻性预测RQ4 是同一快照内的同期关联，不是预测
快照创建时间分布 / 历史完整发布记录只含当前仍可见模型，不是全部历史
任务标签缺失 / 已标注任务unknown 不是一个任务类别，不计入按任务结论
children_count / direct_family_size后者 = 前者 + 1（含自身），均为 1 跳直系
component_size / 家族规模弱连通分量跨多跳，不等于 1 跳家族规模
descendant_count_khop / 全量后代只统计 ≤3 跳，是下界
maintenance_span_days / 更新频率lastModified − createdAt 是维护跨度，不是更新频率
本地单机 / 多节点集群local[N] 单机多核，不构成横向扩展结论
